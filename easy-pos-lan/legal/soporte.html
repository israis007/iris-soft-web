Contacto

Escribe a soporte@irisoft.com.mx. Incluye versión de la app, plataforma, pasos para reproducir el problema y una captura sin datos sensibles.

Para problemas de impresión

  1. Confirma que la impresora esté encendida y vinculada.
  2. Verifica que el dispositivo tenga permiso de Bluetooth o red local.
  3. Prueba la vista previa PDF para separar un problema de diseño de uno de transporte.
  4. No envíes tokens, contraseñas ni números completos de tarjeta.

Para solicitar eliminación o exportación

La identidad autenticada se elimina desde Configuración > Cuenta y datos, escribiendo ELIMINAR después de revisar la advertencia. Para datos comerciales compartidos, indica la cuenta y organización que administras; podemos pedir una verificación de identidad y confirmar qué datos se eliminarán o exportarán antes de ejecutar la solicitud.

Estado del servicio

La operación LAN puede continuar sin internet, pero las funciones cloud, correo, Telegram, RevenueCat y marketplaces dependen de sus respectivos proveedores. Si una integración está desactivada, utiliza el flujo local o comparte el ticket por el sistema operativo.
